# --- THE NULL ANCHOR. |E(HD_BOTK)| from THIS census, on THESE rows, in THIS job.
#   HD_BOTK is the 8 heads the screen ranked LAST. It is the family's own near-null comparator and it
#   is measured alongside everything else, so it needs no external constant and cannot be tuned after
#   the fact. (PR-CSI-013's Rule 2 uses the same anchor for the same reason.)
#   ⚠ It is an 8-HEAD arm and a singleton is a 1-HEAD arm, so this is a DELIBERATELY CONSERVATIVE
#   bar for a singleton: it asks a single head to exceed what eight of the screen's worst do together.
#   A singleton that clears it is clearly non-trivial; a singleton that does NOT clear it is NOT
#   thereby shown to be zero. That asymmetry is stated here so it cannot be read the other way later.

# --- READING A. "AT LEAST ONE HEAD CARRIES DETECTABLE LOAD ALONE"
#   holds iff there EXISTS a head h with  |E(SINGLE_h)| > |E(HD_BOTK)|  AND  E(SINGLE_h) < 0
#   AND ci95(SINGLE_h) excluding 0.
#   (Same three clauses as PR-013's Rule 2, including R21's Amendment 1 sign clause, so the two
#   documents cannot disagree about what counts.)
#   ⚠ DESCRIPTIVE. 32 unadjusted intervals are read at once; this identifies heads worth a
#   PREREGISTERED test, and identifies nothing else. It is not a p-value and no p-value is computed.

# --- READING B. "THE EFFECT IS CARRIED BY THE SET AND IS NOT DECOMPOSABLE PER HEAD"
#   holds iff BOTH:
#     (i)  NO head satisfies Reading A, and
#     (ii) NO LOO marginal -- marginal(h) = E(HD_TOPK) - E(LOO_h) -- has a ci95 excluding 0.
#   Reading B is the outcome the frozen read already called coherent and informative. If it holds,
#   PR-CSI-013 does not launch (its Rule 2(b) fails by construction, since Reading A failing means no
#   head clears the same bar), and THAT IS THE RESULT, not an absence of one.

# --- READING C. NEITHER A NOR B (some head clears the bar, or some marginal excludes 0, but not the
