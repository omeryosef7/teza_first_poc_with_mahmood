# PART 2A -- THE NORM-MATCH DECISION, RESTATED HERE BECAUSE IT DECIDES WHAT THE NUMBERS MEAN
# ================================================================================================
# WHAT --rescue-norm-match-key ACTUALLY DOES, read from the source, not assumed:
#
#  RESOLUTION -- src/boombness/score_behavior.py lines 2271-2277, in make_rescue_basis_loader:
#      if args.rescue_norm_match_key:
#          if args.rescue_norm_match_key not in bases: raise SystemExit(...)
#          nb = bases[args.rescue_norm_match_key]
#  ...where `bases` is blob['bases'] OF THE FILE NAMED BY --rescue-basis. THE NORM-MATCH KEY IS
#  LOOKED UP IN THE SAME FILE AS THE BASIS. IT IS STRUCTURALLY IMPOSSIBLE TO NAME A KEY THAT LIVES
#  IN ANOTHER FILE. That single fact settles half the question before any argument is made.
#
#  ARITHMETIC -- src/boombness/donor_patch.py lines 237-246, SubspaceDonorPatch._hook, per position:
#      delta  = h_donor - h_live
#      proj   = (delta @ W.T) @ W              W = the --rescue-basis-key direction
#      target = ((delta @ Wc.T) @ Wc).norm()   Wc = the --rescue-norm-match-key direction
#      ...and proj is rescaled to `target`.
#  THE NORM-MATCH BASIS IS ONLY A PER-ROW SCALAR YARDSTICK. The data it is measured on is ALWAYS
#  the RECIPIENT's own delta -- the code never has access to the donor codeword's rows. The class
#  docstring at lines 191-194 says it: "the written delta is rescaled per position to the norm the
#  CANDIDATE subspace would have written on this row".
#
# THE CONSEQUENCE THAT COLLAPSES ONE OF THE TWO APPARENT OPTIONS:
#   "Match to the DONOR axis's norm" is not a well-defined second option. Evaluated the only way
#   the code can evaluate it, the donor axis's norm is ||P_donor(delta_recipient)|| -- which IS the
#   swap arm's own unscaled projection norm. Setting --rescue-norm-match-key == --rescue-basis-key
#   makes target == proj_norm and the rescale is the IDENTITY. So "donor norm" and "no norm-match
#   at all" ARE THE SAME ARM. The two genuinely distinct designs are DOSE-MATCHED and NATURAL.
#
# THE DECISION: --rescue-norm-match-key cand_rank1 OF THE RECIPIENT'S FILE. DOSE-MATCHED.
#
#  (1) COMMENSURABILITY, decisive on its own. Every one of the 46 controls was run as
#      `sub KO_RANDi ctrl_randomi cand_rank1` (script groups B/I/K), i.e. norm-matched to
#      cand_rank1. The NATIVE candidate is run as `sub KO_AXIS cand_rank1` with only TWO arguments,
#      i.e. NO norm-match flag -- but because basis == norm-basis is the identity, THE NATIVE
#      CANDIDATE AND ALL 46 CONTROLS ALREADY SIT ON ONE COMMON DOSE SCALE. An arm on a different
#      scale cannot be ranked against them: the ordering would partly measure dose, and a "rank 1"
#      would not mean what rank 1 means for basket.
#  (2) IT ISOLATES DIRECTION FROM DOSE, WHICH IS THE WHOLE EXPERIMENT. At cos = 0.5569 the foreign
#      axis will generically capture LESS of the recipient's delta than the recipient's own axis
#      does -- the recipient's axis was fit to maximise exactly that. Left unscaled, the swap arm
#      would write a systematically smaller perturbation and a null would be uninterpretable,
#      indistinguishable from "too small a dose". C1 versus H_STATE is a question about DIRECTION.
#      Measure direction.
#  (3) The rejected NATURAL design would confound DIRECTION QUALITY with DOSE, and would sit off
#      the control family's scale so that its rank is partly an artifact of the mismatch.
#
# THE NATURAL ARM IS KEPT AS PRESPECIFIED SECONDARY S2 AND IS NOT EXPRESSIBLE BY THE LAUNCHER.
#   Group X ALWAYS passes --rescue-norm-match-key cand_rank1 (line 311, unconditional) and no group
