# THE STATISTIC, PRE-COMMITTED.
#   M = # of ADMITTED heads whose argmax band layer by |E| equals that head's frozen screen layer.
#   H0: the screen's per-cell prediction is unrelated to the button depth profile, so each admitted
#       head's argmax is uniform over the 9 band layers and independent across heads.
#   p = P(Binom(K, 1/9) >= M), one-sided.
#
#     K=3: M=3 -> 0.001372    M=2 -> 0.034294    M=1 -> 0.297668    M=0 -> 1.0
#     K=2: M=2 -> 0.012346    M=1 -> 0.209877
#     K=1: floor 1/9 = 0.1111 -> CANNOT ANSWER for any M
#
#   The frozen screen predictions, on record since commit 94aab78b (2026-09-23 01:05):
#     head 17 -> L14      head 19 -> L14      head 23 -> L7
#
# ⚠⚠ THE SPANNING RULE, AND IT IS THE REASON THIS READ IS TRUSTWORTHY AT ALL.
#   The screen says L14 for TWO of the three heads. If the button intervention carries a shared bias
#   toward the top of the band, M=2 arrives FOR FREE and p = 0.034 would read as a pass while
#   measuring NOTHING about the screen. So SUCCESS additionally requires THE MATCHING HEADS NOT TO
#   BE CONFINED TO ONE BAND LAYER. Basket's own shape (L14, L14, L7) spans two and would satisfy it;
#   "both L14 heads matched, head 23 did not" does NOT, and is CANNOT ANSWER -- whatever p says.
#   This is frozen here, before any number exists, and it is asserted by a test that drives exactly
#   that outcome (tests/test_csi_pr016_argmax.py::test_the_SPANNING_RULE_blocks_the_shared_bias_pass).
#
# ⚠⚠ AND THE SPANNING RULE IS NOT SUFFICIENT. R28 DEMONSTRATED THE RESIDUAL BEFORE ANY ARM RAN.
#   The spanning rule blocks M=2 and leaves M=3 WIDE OPEN. If the button intervention carries the
#   very top-of-band bias this design hypothesises, heads 17 and 19 are pinned to L14 FOR FREE and
#   the ONLY informative event is head 23 landing on L7 -- probability 1/9 = 0.1111, which cannot
#   clear alpha at all. R28 built that world and ran the real reader on it: it printed
#   "K = 3, M = 3, p = 0.001372 ... spanning rule SATISFIED ... VERDICT: PASS". The binomial p would
#   understate the type-I error of the SCIENTIFIC claim by ~81x.
#
#   So TWO ROBUSTNESS CO-PRIMARIES are frozen here, before any number exists:
#     p_conditional   P(Binom(K_unique, 1/9) >= M_unique) over ADMITTED heads whose predicted layer
#                     is NOT shared with another admitted head. With 17 and 19 both on L14,
#                     K_unique = 1 and its floor is 0.1111.
#     p_permutation   the exact permutation p over assignments of the screen's prediction MULTISET
#                     to the admitted heads. It asks whether the screen put the ODD prediction on the
#                     RIGHT head -- which a shared band bias CANNOT fake, because a bias says nothing
#                     about which head gets the minority layer. With {L14, L14, L7} its floor is 1/3.
#
#   ⛔ THESE DO NOT GATE THE PASS/FAIL, deliberately: requiring them would make this family unable to
#      pass for a STRUCTURAL reason (K_unique = 1) rather than an empirical one. THEY BOUND THE
#      WORDING. The headline MUST be stated with the WEAKEST of the three, each named, and quoting
#      the binomial p alone is FORBIDDEN whenever two admitted heads share a predicted layer.
#      S-307 established that as the honest use of a robustness number -- the difference here is that
#      these are frozen BEFORE the run rather than computed after it.
#
# ADMISSION, computed from the whole-head arm ALONE and never from the cells:
#   head h is ADMITTED iff HD_<h>'s ci95 excludes 0 AND |E(HD_<h>)| >= 1.5 x bar(h).
#   ⛔ A DROPPED HEAD IS NOT A MISS. It leaves K, is reported with its measured power, and the floor
#      rises. Head 19 is expected to be admitted (PR-013 measured |E|/bar = 5.69). Heads 17 and 23
#      have NEVER had a button arm and may fail the gate -- that is this family's real risk and it
#      is priced here, not hidden. If it collapses to K=1 the answer is CANNOT ANSWER, and the
#      fallback value is a powered head-level cross-codeword replication of D34 plus a button
#      depth map, which is worth the allocation on its own.
#
