## §10 — ANOMALIES, NAMED

1. ⛔ **`prompt_id` collides 8-way.** 2,736 ids over 21,888 rows, multiplicity exactly 8 (one per lexical bank). Any analysis that joins on `prompt_id` alone silently fans out 8× and mixes `bomb` rows with `club` rows. `prompt_sha16` has 5,020 duplicate-excess rows and is not a fallback.
2. ⛔ **`target_semantic` is a constant, not a label.** It equals `concept` on every row by construction, and it is *wrong* about cells `A`, `D`, `E` and `F`, whose demonstrations install the benign pool word or `bicycle`.
3. ⚠ **`button_gun` installs inconsistently across domains** — 4/6 domains, cell-C mean +0.406, i.e. barely above the boundary, while its Δ (+4.098) is essentially identical to `knife`'s. ⛔ State it as "gun's mapping installs inconsistently across domains", never "gun does not remap".
4. ⛔ **`bomb` installs 2.0×–3.2× harder than the hard negatives** — the low end is against `club`, the high end against `knife`/`gun` (+13.084 vs +6.435, +4.098, +4.089) with far higher option mass (0.836 vs 0.388, 0.451, 0.752). This is `R-078` §21.2's confound: a classifier could separate `bomb` by *degree of remapping* rather than by *which concept*. It is a property of the population, visible here in the metadata, before any probe is fit.
4b. ⛔ **The `R-078` domains+ rule can pass on a cell where the model still reads the codeword LITERALLY.** 6/48 cells have Δ(C−A) > 0 while cell `C`'s own mean log-odds is still **negative** (i.e. the concept option loses): `button_gun`/`farm_storage`/n8 (C=-3.169, Δ=+2.920), `button_club`/`farm_storage`/n4 (C=-1.468, Δ=+3.229), `button_knife`/`farm_storage`/n4 (C=-1.339, Δ=+2.195), `button_club`/`farm_storage`/n8 (C=-0.643, Δ=+5.414), `button_gun`/`city_bridge`/n4 (C=-0.348, Δ=+4.146), `button_knife`/`city_bridge`/n4 (C=-0.296, Δ=+5.730). A paired improvement is not the same as an installed mapping, and this table reports both columns so the two cannot be conflated.
5. ⚠ **The readout inventory is lopsided.** Four `button_*` arms, one query kind, two cells, two dose levels. Half the banks and the entire `semantic_one_word` core population have **no** installation readout on disk. Any claim about `basket_*` or about `semantic_one_word` installation is **unevidenced by the artifacts**, not merely weak.
5b. ⚠ **30/192 joined rows have an argmax that is neither offered option nor ` Neither`** — most frequent: `mushroom`×17, `onion`×5, `clubs`×5, `car`×1, `both`×1, `mush`×1. ⛔ Several of these are *vegetables*, which is the declared design showing through: the benign pool's natural word is `carrot` in **all eight** banks, so cell `A`'s demonstrations install a carrot-like benign object onto the codeword — and the model's argmax lands in that category (`mushroom`, `onion`) rather than on either offered option. That is direct behavioural corroboration that `target_semantic` (which says `bomb`/`knife`/`gun`/`club` here) is FALSE for cell `A`. On such a row `semantic_logodds` is a ratio between two options the model rejected — `R-050`'s readout limit, visible row by row.
5c. ⛔ **Cell `A` is partly the SAME corpus across concept banks** (§2b). Holding the codeword fixed, `bomb` and `club` share a byte-identical cell-`A` demonstration block on 104/696 design cells and a byte-identical WHOLE PROMPT on 82. Every ordered concept pair is affected (42–82 whole-prompt collisions). ⇒ a `bomb`-vs-`club` contrast anchored on cell `A` is, on those rows, a contrast of a prompt with itself, and the `A` anchor is therefore NOT independent across concepts. This was not in the inherited record; `A-020` §8.1 asserted the opposite direction (that cell `A` is a *different* corpus per bank), which holds only modally.
6. ⚠ **`club` is polysemous and its pools use the wrong sense** (`A-020` §8.3). It passes the gate — it installs *something* — which is not the same as installing a weapon sense. The metadata cannot adjudicate that; it only records that the demonstrations install the domain's `|harm` pool word.
7. ⚠ **Cell `C` is not homogeneous.** 96 core-population cell-`C` rows have `demonstration_valence='mixed'` (the consistency arm: half the demos are literal uses of the codeword), and 384 carry an explicit mapping statement in the prompt text. Both are flagged per row rather than folded into cell `C`.
